# YOLO Pipeline Skill: SAM3 Auto-label → Train → ONNX Export

## When to use this skill

When the user needs to:
- Label unlabeled images using SAM3 (text-prompt detection) for YOLO training
- Train a YOLO model (detect/obb/segment) on labeled data
- Export trained YOLO weights to ONNX format
- Run the full auto-labeling → training → export pipeline

## Script location

All pipeline scripts are under `ultralytics/labels/`:

| Script | Purpose |
|--------|---------|
| `pipeline.py` | **Main pipeline** — label / data / train / export / all subcommands |
| `precompute_text_embed.py` | Pre-compute SAM3 text embeddings (run once per prompt) |
| `auto_label_sam3.py` | Standalone SAM3 auto-labeling (ONNX-only, no PyTorch) |
| `fix_labels.py` | Fix class_id format in label files |
| `visualize_labels.py` | Visualize OBB/HBB labels on images for verification |

## Prerequisites

### ONNX Models (must exist before pipeline can run)

These are generated by the ONNX export tools:

```
sam3_backbone.onnx      (1.8 GB) — tools/export_sam3_onnx.py
sam3_detector.onnx      (124 MB) — tools/export_sam3_detector_onnx.py
sam3.pt                 (3.2 GB) — from HuggingFace/ModelScope
```

### Required Packages

```bash
pip install ultralytics onnxruntime-gpu opencv-python pyyaml numpy
```

## Workflow

### 1. Pre-compute text embeddings (once per detection concept)

```bash
cd ultralytics/labels
python pipeline.py precompute --prompt "bag on the conveyor belt"
# Output: sam3_emb_bag_on_the_conveyor_belt.npz
```

### 2. Auto-label images

```bash
# Generate OBB labels (for oriented bounding box training)
python pipeline.py label \
    --images /path/to/images/val \
    --labels /path/to/labels/val \
    --prompt "bag on the conveyor belt" \
    --label-task obb \
    --conf 0.25

# Generate HBB labels (for standard detection training)
python pipeline.py label \
    --images /path/to/images/val \
    --labels /path/to/labels/val \
    --prompt "bag on the conveyor belt" \
    --label-task hbb \
    --conf 0.25
```

### 3. Generate dataset YAML

```bash
python pipeline.py data \
    --dataset-root /path/to/dataset \
    --names "fertilizer bag"
# Output: /path/to/dataset/data.yaml
```

### 4. Train

```bash
# OBB training
python pipeline.py train \
    --data /path/to/dataset/data.yaml \
    --task obb \
    --model /path/to/yolo26n-obb.pt \
    --epochs 100 --batch 16

# Detect training
python pipeline.py train \
    --data /path/to/dataset/data.yaml \
    --task detect \
    --model /path/to/yolo11n.pt \
    --epochs 100 --batch 16

# Segment training
python pipeline.py train \
    --data /path/to/dataset/data.yaml \
    --task segment \
    --model /path/to/yolo11n-seg.pt \
    --epochs 100 --batch 8
```

### 5. Export ONNX

```bash
# ONNX is saved alongside best.pt in the same directory
python pipeline.py export \
    --weights runs/obb/train/weights/best.pt \
    --task obb --half --dynamic

# With NMS embedded (for OBB deployment)
python pipeline.py export \
    --weights runs/obb/train/weights/best.pt \
    --task obb --nms --half
```

### 6. One-shot full pipeline

```bash
python pipeline.py all \
    --images /path/to/images/val \
    --labels /path/to/labels/val \
    --dataset-root /path/to/dataset \
    --task obb \
    --epochs 100 \
    --prompt "bag on the conveyor belt" \
    --names "fertilizer bag"
```

## Task support matrix

| Task | Label format | Pretrained model suffix | `--task` value |
|------|-------------|------------------------|----------------|
| Detection (HBB) | `class cx cy w h` | `.pt` | `detect` |
| Oriented BBox (OBB) | `class x1 y1 x2 y2 x3 y3 x4 y4` | `-obb.pt` | `obb` |
| Instance Segment | `class x1 y1 x2 y2 ...` polygon | `-seg.pt` | `segment` |
| Tracking | Same as detection | `.pt` (use `.track()`) | `detect` |

## Common issues

| Issue | Solution |
|-------|----------|
| GitHub download fails (model not found) | Use local model: `--model /path/to/local/yolo11n.pt` |
| SAM3 OOM (out of memory) | Reduce `--imgsz` or use `--half` (don't use FP32 on CPU) |
| Labels have `0.000000` class ID | Run `python fix_labels.py` |
| Want to verify labels visually | Run `python visualize_labels.py --image frame_0000` |
| ONNX Export fails for OBB | Set `--nms` flag for OBB models with embedded NMS |
| Training uses wrong label format | Check `--label-task` matches `--task` (hbb→detect, obb→obb) |
